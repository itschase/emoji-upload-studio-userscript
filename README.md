# Emote Forge Upload Studio Bridge

Public distribution mirror for the Tampermonkey userscript used by [Emote Forge Upload Studio](https://emote-forge.itschase.workers.dev/).

The userscript and Upload Studio are separate components. Their release versions must match for uploads to run. Install or update through [Greasy Fork](https://greasyfork.org/en/scripts/605370-emoji-gg-upload-studio-worker) or use the update action inside Upload Studio.

This repository intentionally contains only the browser userscript and its license. The Upload Studio application and backend are maintained separately.
